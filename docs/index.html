Course design advice that shows its sources.

idstack reviews your course in Claude Code or Chrome. Each recommendation names the study behind it and how strong that evidence is, from T1 meta-analyses and RCTs to T5 expert opinion. 108 peer-reviewed studies across 11 research domains.

Add to Chrome Free or via Claude Code:
$ git clone https://github.com/savvides/idstack.git && cd idstack && ./setup
→  See the 108 studies

Open source MIT v3.9.0.0 · Claude Code & Chrome Extension

Every recommendation cites its source.

The 11 research domains below are ranked by study count. Each bar shows the tier mix of that domain's references. You can see where idstack rests on trials and where it rests on reviews or expert opinion. Stronger evidence tiers take precedence when findings conflict. All 108 references are listed in evidence/references.md. Every source is public, and every citation can be checked.

T1 meta-analyses & RCTs T2 quasi-experimental w/ controls T3 systematic reviews T4 observational T5 expert opinion & theory

  1. Cognitive Load Theory & Instructional Sequencing

    15 studies

    Working memory limits the volume of novel information learners process simultaneously. Intrinsic and extraneous load principles determine when visual cues clarify concepts and when redundant explanations induce cognitive overload. T1–T5

  2. Instructional Design Models & Frameworks

    12 studies

    ADDIE, ARCS, ASSURE, and UDL address distinct instructional contexts. A 2025 review [ID-7] [T3] compares the strengths and limits of ADDIE, ARCS, and ASSURE. It proposes a framework that combines them. T2–T5

  3. Constructive Alignment & Learning Objectives

    10 studies

    Misalignment between objectives, activities, and assessments directly degrades learning retention. Revised Bloom's taxonomy provides measurable action verbs to align evaluation criteria with intended cognitive levels. T1–T5

  4. Formative Assessment & Feedback

    10 studies

    Elaborated feedback that explains error patterns and corrective action yields significantly higher retention than simple correctness indicators. Nicol's principles structure criteria for rubrics, self-assessment, and peer review. T1–T5

  5. Multimedia Learning Principles

    10 studies

    Mayer's cognitive principles (coherence, signaling, segmenting, modality, redundancy) govern effective integration of text and graphics. Violations generate extraneous cognitive load and impair knowledge transfer. T1–T5

  6. Online Course Quality Frameworks

    10 studies

    Quality Matters (QM) standards and the Community of Inquiry (CoI) model (teaching, social, and cognitive presence) are the most extensively validated rubrics for online course quality. idstack audits against both. T1–T4

  7. Rapid Prototyping & Design-Based Research

    9 studies

    Formative pilot testing with representative cohorts surfaces usability and conceptual bottlenecks early. Design-based research frameworks ensure iterative revisions maintain methodological rigor. T2–T5

  8. Accessibility & Universal Design for Learning

    9 studies

    WCAG 2.1 AA establishes the legal baseline for digital accessibility. Universal Design for Learning (UDL 3.0) plans three pathways (engagement, representation, and action) from the start of design, to support diverse learners. T1–T5

  9. Learner Analysis & Differentiation

    8 studies

    Prior knowledge is the strongest predictor of instructional efficacy. Differentiated scaffolding supports novice skill acquisition while avoiding the expertise-reversal effect on advanced learners. T1–T5

  10. Evaluation Models

    8 studies

    Assessment strategies must be designed concurrently with course architecture. Kirkpatrick's four-level model structures evaluation across reaction, learning, behavior, and institutional results. T3–T5

  11. Needs Analysis

    7 studies

    Needs analysis evaluates three distinct levels (organizational, task, and learner) before content development begins. Systematic needs assessment prevents courses from addressing peripheral topics instead of core skill gaps. T3

Every recommendation includes a research domain code and evidence tier (such as [Alignment-14] [T1]) linking directly to the cited paper.

Eleven skills. Pipeline optional.

Eight skills execute sequentially through /idstack:pipeline, while two standalone skills handle course import and institutional memory. You can run any skill independently on existing course files without creating an upfront manifest.

Sequence (left to right) under /idstack:pipeline

  1. needs-analysis Three-level needs assessment; design-fit gate.
  2. learning-objectives Bloom's classification; bidirectional alignment.
  3. assessment-design Rubrics, checkpoints, Nicol's 7 feedback principles.
  4. course-builder Cognitive-load-aware content generation.
  5. course-quality-review QM 8 standards + Community of Inquiry.
  6. accessibility-review WCAG 2.1 AA + UDL 3.0 audit.
  7. red-team Adversarial audit across 5 dimensions.
  8. course-export Common Cartridge, SCORM 1.2, or Canvas API.
course-import Extracts existing modules, assignments, and syllabi from Canvas API, IMSCC, or SCORM.
learn Manages cross-project institutional knowledge, design preferences, and recurring findings.

Run the complete workflow with /idstack:pipeline. It tracks course state, skips completed skills, and resumes automatically across sessions.

Each skill writes both a report and a manifest.

Every analytical skill outputs two artifacts: a standalone HTML report formatted for faculty and stakeholders, and a structured JSON manifest consumed by downstream skills. Files are organized in .idstack/exports/<course-slug>/.

HTML · .idstack/exports/<course-slug>/learning-objectives.html

Finding obj-3: Unassessed Intended Learning Objectives warning T1

Observation. 3 of 8 stated learning objectives have no associated assessment items.

Empirical Evidence. Constructive alignment requires direct correspondence between objectives, activities, and assessments. Unassessed objectives correlate with lower learning gains. [Alignment-14] T1

Recommendation. Run /idstack:assessment-design to generate aligned assessment rubrics, or update the objective list.

HTML reports are self-contained with bundled assets for distribution to faculty and curriculum committees. JSON manifests preserve machine-readable state for downstream tools. The project timeline at .idstack/timeline.jsonl records audit history, and /idstack:pipeline builds an index.html dashboard that summarizes all findings.

Two ways to install.

Chrome Extension

In-Browser (Canvas / Docs)

Audit Canvas course modules, assignments, Google Docs syllabi, and web course pages directly in a native Side Panel. Zero command-line setup.

Install from Chrome Web Store Free

Claude Code Plugin

Full 11-Skill Pipeline
$ git clone https://github.com/savvides/idstack.git && cd idstack && ./setup

./setup registers idstack with Claude Code and installs all 11 skills. Re-run it after a git pull to update.

Requires a bash shell (Terminal on macOS or Linux, WSL or Git Bash on Windows). ./setup does not run in PowerShell or cmd. Requires Python 3.9 or later: the skills save their results with it. bin/idstack-doctor checks for it.

To verify an installation, run bin/idstack-doctor to diagnose plugin registration or bin/idstack-status to view course health.

New to Claude Code? Download it first (free), then paste the command above. When Claude Code starts, run /idstack:pipeline.

Not using Claude Code? The idstack skills run in Claude Code only. Use the Chrome extension, or fork the repo and adapt the skills for a different agent, for example Codex or Antigravity. idstack does not support or test those forks.
